A LITTLE UNIVERSE — MEN'S DAY WEBSITE

HOW TO USE
1. Extract this ZIP file.
2. Open the folder in Acode.
3. Open index.html in preview/browser.
4. All five pages are connected through the navigation at the top.

PERSONALISE IT
- Edit the text in the HTML files to add his name, your inside jokes and your own letter.
- In little-things.html, replace each placeholder <div class="placeholder"...>...</div> with:
  <img src="images/photo1.jpg" alt="A favourite memory">
- Create an 'images' folder and put your pictures inside it. Use matching file names.
- Change the photo captions below each image.
- Edit the final secret message in final.html.

NOTES
- The Google Fonts import needs an internet connection; the page still works with fallback fonts.
- This is a static website. To share it as one link, upload the folder to GitHub Pages or another static website host.
- Keep all HTML files, style.css and script.js together in the same folder.
